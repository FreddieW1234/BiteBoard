Stock designs — quick merge into live office app.py
===================================================

Your pasted app.py already has the stock-design routes. You only need:

1) Create the folder at startup (so it always exists under DB_DIR):

   Right after ORDERS_DIR.mkdir(...), add:

       (DB_DIR / "stock designs").mkdir(parents=True, exist_ok=True)

2) Restart the Office Order API service.

3) Confirm path: open http://127.0.0.1:8000/ (or your HOST:PORT). Optionally
   add to the health JSON:

       "stock_designs_dir": str(DB_DIR / "stock designs")

   Look THERE for the folder — not a random "data" next to a copy of app.py.

4) From Product Creator (edit an existing product): pick a ZIP → it should
   upload immediately and create:

       {DB_DIR}/stock designs/{shopify_product_id}/{Product Name}_v1.zip

Portal side (Render) was fixed to buffer the ZIP bytes so the office API no
longer receives an empty upload.
